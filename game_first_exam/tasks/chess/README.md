# PettingZoo Chess Standard smoke

The `chess` suite freezes one standard-start match. Its current engineering condition uses White as the sole evaluated player and a deterministic Black policy. The provisional policy permits public tools, including chess engines, subject to the task-specific answer restriction. This condition measures a coding agent operating a chess client with those tools. Tool policy, observation profile, budget and match scoring are pending benchmark review.

The simulator uses AEC `classic/chess-v6` (PettingZoo 1.27.0), with chess 1.11.2 on Python 3.12. Source hashes and the simulator's Windows x64 and Linux x86-64 dependency locks are kept with the [adapter](../../benchmarks/chess). The engine receives one reset to the standard board. One client decision executes one native call for White and at most one native call for Black. The policy sorts the native legal map by absolute UCI and indexes it with SHA-256 of the frozen opponent seed, history length and UCI history.

`chess-public-board-native-v1` publishes the unmodified white-view tensor and mask as lists, alongside derived FEN, board text, move map, history and outcome. The native initial history planes are zero. The native mask may remain nonzero at termination while the public legal map is empty. Legal action IDs use the action encoding of the current native player. Public move text always uses absolute UCI.

A mask-zero ID within the action space ends the episode through the native wrapper, with White reward −1, Black reward 0 and both native flags set. The service rejects unknown strings before they reach the simulator. The engine ends the game when it detects claimable draws, including a draw that could be claimed on the next move. Public exhaustion preserves the unfinished status and actual native flags.

`match_points` is 100 for White checkmate, 50 for a draw and 0 for loss, illegal move or unfinished games. The independent verifier validates the score, native rewards and flags, action counts, a hash-bound per-attempt trace and Black's choices from the recorded legal map. It trusts the isolated sim's reported positions and legal maps. Each event includes the actor, legal map, ID and UCI, rewards, flags, decision index, ply and FEN transition. Rejected requests are recorded by the shared service. The shared video captures the initial board and one frame after each public decision.
