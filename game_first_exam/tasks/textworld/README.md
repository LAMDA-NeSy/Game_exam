# TextWorld integration

Nine frozen games generated by official TextWorld 1.7.0 challenges: Coin Collector, Treasure Hunter and Cooking, three seeds each. Original .z8/.json assets are unchanged and executed through native TextWorld/Jericho. Native cumulative score is converted to reward increments once; victory and normalized score are preserved.

No added action-count limit (max_steps=null). Native game endings, Agent exit and the declared wall-clock budget still end a trial. Player-visible feedback/description/inventory/objective come directly from EnvInfos. The parser handles vocabulary, case and unknown commands. Only interpreter controls, reset/undo and multi-command input are rejected; the one-episode trust boundary is not relaxed.

Run `scripts/run_games.py --suite textworld`. This is a frozen challenge subset, not the full competition dataset. See [framework](../../../docs/game_framework.md).
